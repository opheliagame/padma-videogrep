# on syntax

| phrase                      | meaning                                                                                          |
| --------------------------- | ------------------------------------------------------------------------------------------------ |
| `you`                       | you                                                                                              |
| `me`                        | me                                                                                               |
| `climate change`            | the phrase "climate change"                                                                      |
| `water and rain`            | both water and rain in the same media item(s)                                                    |
| `water AND rain`            | both water and rain in the same media item(s)                                                    |
| `water or rain`             | either water or rain in the same media item(s)                                                   |
| `water OR rain`             | either water or rain in the same media item(s)                                                   |
| `(water and river) or rain` | water and river together in the same media item(s), combined with rain in the same media item(s) |
| `water and (river or rain)` | water in the same media item(s) and river or rain together in the same media item(s)             |

# on controls

- **length** — clip duration: short (under 5s), medium (5–15s) or long (over 15s).
<!-- - **sort** — order of clips: relevance, date or random. -->
- **clip count** — how many clips per scene, from 1 to 50 (default 10).
