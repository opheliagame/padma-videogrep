## Overview

This project provides:
- **Complex Boolean Queries**: AND/OR operators with proper precedence
- **Abstract Syntax Tree (AST)**: Full AST generation and validation
- **Build System**: Webpack bundling for browser compatibility
- **Modular Architecture**: Components for write/play modes
- **API Integration**: Direct integration with Pad.ma API

## Quick Start

### Building
```bash
npm run build          # Build grammar and webpack bundle
npm run build:parser  # Just compile grammar
npm run build:bundle  # Just webpack bundle
```

### Testing
```bash
node app/api/service.test.js
```

### Browser Usage
The parser is loaded automatically via `dist/nearley-bundle.js` in index.html:
```javascript
// Parse a query
const ast = window.nearleyParser.parse("water and bucket");
console.log(ast); // AST node with type and operands
```

### Script Loading Order

As defined in `index.html`, scripts load in this order:

1. **OxJS framework** (`min/Ox.js`)
2. **Nearley Bundle** (`dist/nearley-bundle.js`) - Contains parser
3. **Utilities** (`app/utils/parser.js`) - SceneParser wrapper
4. **API Service** (`app/api/service.js`) - API communication
5. **Components** (`app/components/*.js`) - UI components
6. **Main App** (`index.js`) - Application initialization

This order ensures all dependencies are available before use.

### Module Descriptions

#### Utils (`app/utils/`)

- **scene-query.ne**: Nearley grammar definition for query parsing
  - Defines tokens: KEYWORD, AND, OR, LPAREN, RPAREN, whitespace
  - Defines rules with proper operator precedence

- **nearleyParser.js**: Compiled grammar output (auto-generated by nearleyc)
  - Contains lexer rules and parser rules
  - Used by webpack bundle

- **nearleyEntry.js**: Webpack entry point
  - Creates browser-compatible parser wrapper
  - Exports `window.nearleyParser` for use throughout app

- **nodeParser.js**: Node.js parser for testing
  - Same interface as browser parser
  - Used by test suite (service.test.js)

- **parser.js**: SceneParser wrapper
  - `window.SceneParser.parse(sceneText)` - Main parsing function
  - Returns: `{ keywords, operator, originalText, ast }`
  - Handles both AST parsing and backward-compatible keyword extraction

#### API (`app/api/`)

- **service.js**: Handles all API communication with Pad.ma
  - `APIService.findByTranscript()` - Low-level API call wrapper
  - `APIService.findClipsByTranscript()` - High-level clip fetching
  - `APIService.findClipsByAST()` - AST-based query execution
  - `astToQueryCondition()` - Converts AST to API query format

- **service.test.js**: Comprehensive test suite
  - Tests AST generation for various query types
  - Validates operator precedence
  - Verifies flattening of consecutive operators
  - 6/6 tests passing

#### Components (`app/components/`)

- **header.js**: Application header with title and mode toggle
  - `HeaderComponent.create(app)` - Creates header element
  - Toggle between write mode and play mode

- **sceneBuilder.js**: Scene input interface for write mode
  - `SceneBuilderComponent.create(app)` - Creates textarea inputs
  - `SceneBuilderComponent.initializeScenes(app)` - Parses all scenes
  - Parses user input to extract AST and keywords
  - Updates scene data model in real-time
  - Stores both `queryText` and `ast` on each scene
  - Supports complex queries: `"water and bucket"`, `"(water or rain) and bucket"`

- **playPanel.js**: Video player and clip list for play mode
  - `PlayPanelComponent.create(app)` - Creates video + clip list layout
  - `PlayPanelComponent.renderClipList(app, items)` - Renders clip list
  - Handles video playback and clip metadata display

- **ui.js**: Main UI orchestrator
  - `UIComponents.mainPanel(app)` - Routes between write/play modes
  - `UIComponents.fetchClips(app)` - Fetches clips from all scenes
  - `UIComponents.playClips(app, items)` - Plays clips sequentially
  - Uses `scene.ast` for AST-based queries
  - Falls back with warning if no AST available

#### Core Application

- **index.html**: Entry point, loads all scripts in dependency order
- **index.js**: Main application state management and initialization
  - `app.data.screenplay.scenes` - Array of scene objects
  - Each scene has: `{ queryText, ast, ...otherProperties }`
  - Initializes parser after API loads
- **index.css**: Global application styles

### Key Global Objects

```javascript
window.nearleyParser         // Parser from webpack bundle
```

### Data Flow

**Write Mode:**
1. User edits scene textarea
2. `sceneBuilder.js` detects change
3. `SceneParser.parse()` processes text
4. AST and keywords stored on scene object
5. Real-time preview updates

**Play Mode:**
1. Click "Play Mode" button
2. Switch UI to play panel
3. Click "Fetch Clips"
4. `UIComponents.fetchClips(app)` processes all scenes
5. For each scene: `APIService.findClipsByAST(app, scene.ast, callback)`
6. API executes query using AST structure
7. Clips displayed in video player

## Parser System

### Query Grammar

```
Query → Expression
Expression → Term (OR Term)*          // Lower precedence
Term → Factor (AND Factor)*           // Higher precedence
Factor → KEYWORD | (Expression)
```

### Operator Precedence

**AND has higher precedence than OR:**

```
a or b and c
→ a OR (b AND c)

a and b or c
→ (a AND b) OR c
```

### AST Structure

**Keyword Node:**
```javascript
{
  type: "KEYWORD",
  value: "water"
}
```

**AND Operator:**
```javascript
{
  type: "AND",
  operands: [
    { type: "KEYWORD", value: "water" },
    { type: "KEYWORD", value: "bucket" }
  ]
}
```

**OR Operator:**
```javascript
{
  type: "OR",
  operands: [...]
}
```

### Operator Flattening

Consecutive same operators are flattened to single node:

```
water AND bucket AND coffee
→ {
    type: "AND",
    operands: [
      { type: "KEYWORD", value: "water" },
      { type: "KEYWORD", value: "bucket" },
      { type: "KEYWORD", value: "coffee" }
    ]
  }
```

NOT nested:
```
{
  type: "AND",
  operands: [
    {
      type: "AND",
      operands: [water, bucket]
    },
    coffee
  ]
}
```

## Integration

### Scene Storage

Each scene object stores both text and parsed AST:

```javascript
{
  id: "scene-1",
  queryText: "water and bucket",
  ast: {
    type: "AND",
    operands: [
      { type: "KEYWORD", value: "water" },
      { type: "KEYWORD", value: "bucket" }
    ]
  }
}
```

### API Integration

Convert AST to API query conditions:

```javascript
// In service.js
function astToQueryCondition(node) {
  if (node.type === "KEYWORD") {
    return {
      key: "transcripts",
      value: node.value,
      operator: "="
    };
  }
  
  if (node.type === "AND") {
    return {
      conditions: node.operands.map(astToQueryCondition),
      operator: "&"
    };
  }
  
  if (node.type === "OR") {
    return {
      conditions: node.operands.map(astToQueryCondition),
      operator: "|"
    };
  }
}
```

### UI Usage

```javascript
// In ui.js
if (scene.ast) {
  // Use AST-based search
  APIService.findClipsByAST(app, scene.ast, function(clips) {
    // Handle results
  });
} else {
  // Fallback with warning
  console.warn("Scene has no AST");
}
```

## Development

### Adding New Components

1. Create file in `app/components/` folder
2. Define component with namespace (e.g., `MyComponent`)
3. Create methods following pattern: `MyComponent.create(app)`
4. Add script tag to `index.html` before `index.js`
5. Use in `ui.js` or other components

### Modifying Grammar

1. Edit `app/utils/scene-query.ne`
2. Run `npm run build:parser` to compile
3. Run `npm run build:bundle` to update webpack bundle
4. Test: `node app/api/service.test.js`

### Adding Test Cases

Edit `app/api/service.test.js` and add new test case:

```javascript
{
  input: "your query here",
  expected: { /* expected AST */ }
}
```

Then run:
```bash
node app/api/service.test.js
```

## Troubleshooting

### Parser not loading
Ensure `dist/nearley-bundle.js` is loaded before components use `window.nearleyParser`.

### Tests failing
Run `npm run build` to recompile grammar and bundle:
```bash
npm run build
npm run test
```

### Grammar errors
Update `app/utils/scene-query.ne` and rebuild:
```bash
npm run build:parser
npm run build:bundle
npm test
```

### AST not available on scene
Ensure `SceneBuilderComponent.initializeScenes(app)` is called in `index.js` after parser loads.
